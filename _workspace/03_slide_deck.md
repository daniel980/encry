### 4. 공통 컴포넌트 (00c 컴포넌트 체계)

- **네이비 솔리드 헤더 바**: 테이블·박스 제목용 — `#17375E` 솔리드 사각형(라운드 0~4pt) + 백색 12pt Bold. 모든 테이블 헤더 행에 적용.
- **회색 라벨 칩**: 행 레이블·구획 라벨용 — `#F1F3F5` 배경 + `#4B5563` 텍스트 10.5pt, 라운드 10pt 알약형.
- **얇은 실선 테두리 흰 셀**: 데이터 값 셀 — 백색 배경 + `#C9D2DE` 0.75pt 테두리. 합계·결론 열은 라운드 테두리 박스로 강조.
- **라운드 콜아웃 박스**: 라운드 사각형(8pt) + 좌측 상단 **네이비 탭**(항목명 백색 11pt Bold) + 내부 불릿 목록 12pt.
- **진행 상태 도트 + 범례**: 🟢 On-track / 🟡 Potential for Delay / 🔴 Blocker — 진도 표시 열에 사용, 사용 슬라이드 상단에 범례 스트립 배치. 본 덱의 4상태 기호 ● 완비(`#76B900`) / ○ 부분·계획(`#D97E00`) / △ 제한적(`#6B7280`) / ✕ 미보유(`#C0392B`)는 02 문서 콘텐츠 규칙으로 유지하되, **동일하게 테이블 상단 범례 스트립 패턴으로 표기** (기호+색 병기).
- **결정 카드 (슬라이드 2·12 수미상관 모티프)**: 라운드 사각형(모서리 6pt), **`#17375E` 네이비 솔리드**, 백색 텍스트. 내부 — 좌측 체크박스(백색 테두리 사각형 16×16pt, "☐"), 우측 1행 "D# 제목"(13pt Bold 백색), 2행 한 줄 설명(11pt `#C7D3E2`). **슬라이드 2(컴팩트형)와 12(풀사이즈형)에서 동일 디자인 언어(솔리드 네이비+체크박스+D# 서체) 유지.**
- **스크린샷 플레이스홀더 프레임 (유지)**: 16:9 비율, 배경 `#F1F3F5` + 대각선 패턴(`#D5D9DE` 1pt 45°), 테두리 `#6B7280` 1.5pt 파선, 중앙 "🖼 대시보드 스크린샷" 12pt + **"SKT 제공 예정"** 알약 라벨(백색 배경, `#6B7280` 테두리, 11pt Bold), 프레임 하단 외부 캡션(10pt).
- **범례 스트립 (3색 다이어그램·매트릭스 하단)**: "🟩 DSX OS 기본 제공 🟦 SKT 개발 🟧 공동 개발" — 10.5pt, 각 항목 앞 11×11pt 색상 칩(본색 테두리+틴트 채움. 🟦=네이비 `#17375E`/`#DEE5EF`).
- **다이어그램 화살표**: 일반 흐름 = 회색 `#9CA3AF` 실선 1.5pt, 보조·참조 = 회색 점선, 강조(결론 방향) = 네이비 `#17375E` 2pt. 순서 표기는 번호 뱃지(●1 스타일, 네이비 원+백색 숫자).
