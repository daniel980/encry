## 슬라이드 유형별 규칙

### 1) 표지
- 중앙에 큰 검정 볼드 제목 + 아래 얇은 회색 언더라인(중앙 구간만 굵은 회색).
- 하단 중앙: 일자('26년 1월 형식) + 조직명 (SKT AI CIC / AI Infra TF).
- 최하단: 점선 테두리 박스의 [For Discussion Purpose Only] 면책 문구 (작은 글씨).
- (우상단 법무검토 테이블은 본 덱에서는 불필요 — 생략)

### 2) 목차 (Table Of Contents)
- 좌상단 헤더: **네이비 세로 바(이중: 진한+연한) + 볼드 타이틀** "Table Of Contents".
- 본문: 큰 볼드 항목 번호+제목, 오른쪽 위첨자 스타일 소괄호 주석 (담당 조직).

### 3) Executive Summary
- 좌측: 네이비 솔리드 박스(흰 글씨, 번호+항목명, 세로로 3개).
- 우측: 얇은 네이비 테두리 흰 박스에 불릿 2~3개. 키워드는 [대괄호] 로 선행 표기.

### 4) 섹션 디바이더
- 전체 다크 네이비 배경 + 중앙 흰색 볼드 "N. 섹션명".

### 5) 본문 슬라이드 공통
- 좌상단 헤더: 네이비 세로 바 + "N-N. 소제목" 볼드 (네이비). 우상단에 보조 라벨(회색/네이비 소제목) 가능.
- 헤더 아래 **중앙 정렬 볼드 거버닝 메시지 1문장** (검정, 본문보다 큰 글씨) — 이 덱의 "주장형 헤드라인" 위치.
- 본문 컴포넌트:
  - **네이비 솔리드 헤더 바**: 테이블/박스 제목 (흰 글씨, 라운드 없음 또는 약간)
  - **회색 라벨 칩**: 행 레이블 (연회색 배경, 진회색 글씨)
  - **얇은 실선 테두리 흰 셀**: 데이터 값. 합계 열은 라운드 테두리 박스 강조
  - **라운드 사각형 콜아웃**: 항목명 네이비 탭 + 불릿 목록
  - **진행 상태 도트**: 🟢 On-track / 🟡 Potential for Delay / 🔴 Blocker — 우측 "진도" 열, 상단에 범례
  - 강조 수치는 볼드 검정, 보조는 회색
- 다이어그램: 흰 배경 + 네이비/회색 박스, 점선 화살표(회색), 강조 화살표(마젠타/퍼플 계열), 번호 뱃지(●1 스타일)
